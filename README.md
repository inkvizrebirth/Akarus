## Главное

- полностью свои главное меню, пауза, настройки, миры и серверы;
- ClickGUI со стеклом, поиском, темами и анимациями;
- перетаскиваемый HUD: Target HUD, эффекты, броня/оффхенд, keystrokes + CPS, сессия, бинды, уведомления и музыка;
- KillAura, Scaffold (Normal/Legit/Telly), AutoBuff с питьём и splash-зельями, AutoTotem, NoFall, ESP, Trails, FreeCam/FreeLook, Baritone-модули и другое;
- визуальные модули одним слоем: ChinaHat, Wings, Target ESP и Motion Blur через ванильные пост-цепочки 26.2;
- встроенные ViaFabricPlus 4.6.3, Sodium, Lithium, ImmediatelyFast и Mod Menu.

![ClickGUI](docs/preview-clickgui.png)

## Установка

1. Установи Fabric Loader для **Minecraft 26.2** и Fabric API `0.159+`.
2. Скачай `dreamcast-1.1.4.jar` из [Releases](https://github.com/inkvizrebirth/Dreamcast/releases) и положи в `.minecraft/mods`.
3. Запусти игру на Java 25.

## Повороты (KillAura, Scaffold, AutoBuff)

Все модули, которые куда-то целятся, пользуются одним слоем поворотов: очередь по
приоритету (аура → бафф → билд), один владелец на тик, доворот с ограничением
скорости и «отпущенный» взгляд игрока, который не ломает мышь. Режимов три:

| Режим | Что делает |
|---|---|
| **Сайлент** | камера не двигается вообще; разворот уходит только в пакет движения — сервер видит прицел, игрок ничего не замечает |
| **Видимый** | как в старых клиентах: игрока реально доворачивает, после модуля взгляд возвращается на место |
| **Нет** | модуль целится туда, куда уже смотрит игрок, и бьёт/ставит только если попал в допуск |

«Скорость поворота» (°/тик, `0` — мгновенно) есть у ауры, Scaffold и AutoBuff; у ауры
дополнительно — «Легитный доворот» (очеловечивание) и «Движение» (свободное,
легитное, фокусированное — последнее умеет вести игрока к цели и в сайлент-режиме).
Имена настроек не менялись, старые конфиги открываются как раньше.

## Визуальные модули

ChinaHat, Wings и Target ESP рисуются нашим world-рендером (см. `WorldRenderHook`),
а не партиклами: выключил опцию — в тот же кадр всё пропало, никаких «довисевших»
эффектов. Данные модуль собирает на извлечении кадра, рендер только читает
неизменяемый снапшот — поэтому ни один из трёх не дёргается, когда игра стоит на
20 тиксах, а монитор крутит 240 Гц.

| Модуль | Основные настройки | Что рисует |
|---|---|---|
| **ChinaHat** | высота, радиус, сдвиг по Y, сегменты, вращение (°/с), цвет/радуга, ободок, светотень, «на цели ауры», «от первого лица» | конус-шляпа на макушке: `segments` граней, яркость грани зависит от её разворота к камере, поэтому конус читается объёмным, а не плоским веером |
| **Wings** | показывать (всегда / в движении / в воздухе), на себе, на игроках, обводка и рёбра, размер, частота взмахов, плотность, цвет/радуга | два контура по 13 точек за спиной в три слоя (ореол → ядро → тело): крыло захлопывается на бегу, поднимается в прыжке, раскрывается в элитрах; взмах считается по частичному тику |
| **Target ESP** | стиль (орбы / кометы / кристаллы / рой / кольцо / маркер), анимация (расти / угасать / нет), длительность, элементов, длина хвоста, скорость, размер, радиус орбиты, плотность, цвет/радуга, «держать последнюю позицию», «цвет по здоровью» | эффект вокруг текущей цели — той же, что у ауры, а без неё того, на что наведён прицел: кольцо с «юбкой», рамка в плоскости экрана, орбы с хвостами, октаэдры-кристаллы, рой точек |
| **Motion Blur** | сила (мягкое / среднее / сильное), компенсировать герцовку | размытие в движении поверх кадра: история копится в persistent-таргете пост-цепочки, размываются только пиксели, которые изменились между кадрами — статичная сцена остаётся резкой |

Два ограничения, оба — про то, как устроен рендер в 26.2:

- **крылья всегда идут с тестом глубины** (в референсе это режим «не через тело»).
  Вариант «сквозь стены» не портирован: под него нужен отдельный RenderType без
  глубины, то есть своя очередь в submit-пайплайне, и крылья начали бы рисоваться
  поверх ландшафта и HUD в любом кадре.
- **сила размытия — три пресета, а не ползунок.** Uniform'ы пост-цепочки в 26.2
  читаются из JSON при загрузке, публичного способа поменять их на лету нет,
  поэтому модуль переключает целую цепочку (`assets/dreamcast/post_effect/*.json`),
  а не её параметр.

С Iris Motion Blur несовместим: шейдер-паки подменяют пайплайн, и цели нашей
цепочки в нём не существуют — модуль пишет причину в чат и держит эффект
выключенным, пока Iris не убрать.
NoBlind с ним не конфликтует: тот гасит только `nausea`-цепочку.
